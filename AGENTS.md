# GitHub Pages release maintenance

- The owner requires this GitHub Pages site to be updated for every app release, including 1.6.0. This is part of release completion.
- Keep the existing GitHub Pages hosting on `codex/privacy-pages` at `/`; do not migrate hosting.
- Review current source behavior, changelog, user guides, displayed version, versioned links, screenshot captions and all three privacy policies. Update actual content, not only the version string.
- Preserve the Google Play recruitment form as the primary action. Do not equate a GitHub release or an Alpha draft with Play publication.
- Check local links, publish the website branch, wait for Pages deployment and verify public content. Keep release tags and signed artifacts immutable.
