FAULT-BASED CAMERA / ANDROID

壊れた信号を、
写真にする。

光が画像になる、その途中を壊す。
13種類のFAULTを選び、重ねて、
自分だけの壊れたカメラを組み立てる。
壊れ方の個性を保ちながら、
その瞬間にしかない崩れを写します。

ONE BROKEN SYSTEM

壊れ方に、個性を。
その瞬間に、偶然を。

壊れ方を決める「個体」、連続する「揺らぎ」、
一時的な「事故」。3つを分けて設計しています。

IDENTITY / 個体

壊れ方のくせが、残る。

故障が起きやすい位置や偏りを、カメラの個性として保ちます。時間がたっても、選んだFAULTの組み合わせや個体は変わりません。

MOTION / 揺らぎ

同じ個体が、揺らぎ続ける。

読み出しのずれや露光のタイミングが、連続して変化します。FAULTごとの揺らぎが、同じ被写体に違う表情を生みます。

EVENT / 事故

一瞬の事故が、割り込む。

流れ続ける映像に、一時的な欠落や誤読が起こります。個体のくせや連続した揺らぎに、その時だけの崩れが加わります。

8 FAULT POINTS / 13 FAULTS

光が画像になる、
その途中へ。

FAULTは、信号が画像になる8つの段階に対応。
選んだ順番にかかわらず、この流れに沿って重なります。

  1. 01

    SENSOR

    撮像素子

    PIXEL DAMAGE

    暗い点、明るい点、縦に連なる画素の故障。

    EXPOSURE

    露光の欠落や、タイミングのずれによる帯。

  2. 02

    READOUT

    読み出し

    ROW ERROR

    読み出す行のずれや欠落、帯状の崩れ。

  3. 03

    DATA

    データ

    BIT ERROR

    画素データのビットが反転し、局所的に色や明るさが崩れる。

    ADDRESS ERROR

    読み取る位置のずれや領域の誤読。

  4. 04

    CFA / RECONSTRUCTION

    色の復元

    CFA ERROR

    色フィルター配列の対応がずれ、色の復元が崩れる。

    DEMOSAIC ERROR

    誤った周辺画素から色を補い、輪郭や細部が崩れる。

  5. 05

    COLOR

    色

    CHROMA ERROR

    明るさと色の成分を分け、色だけをずらす。

    COLOR MAP

    色の割り当てや繰り返しを変え、別のパレットへ。

  6. 06

    CODEC / STREAM

    圧縮・ストリーム

    BLOCK ERROR

    ブロックごとに階調が欠けたり、画像が崩れたりする。

    STREAM ERROR

    画像の一部が欠け、同じフレームの別の部分に置き換わる。

  7. 07

    MEDIA

    記録媒体

    VHS

    テープ特有のにじみ、トラッキングの乱れ、信号の欠落やノイズ。

  8. 08

    DISPLAY

    表示

    CRT

    走査線や蛍光体の質感に、色ずれや同期の乱れを加える。

CLEANはFAULTを適用しない状態です。LEVELを上げると、それぞれのFAULTに応じて故障の密度やずれ幅、事故の影響が変わります。ADVANCED MODEでは、内部の値を自動調整に任せるか、自分で固定するかを選べます。

実験機能を有効にすると、MOTION BLUR・THERMAL NOISE・SMEARも使えます。端末の状態に各FAULTが反応する強さも調整できます。実験機能とADVANCED MODEは、初期設定ではOFFです。

ONE SCENE / THREE SIGNAL PATHS

ひとつの景色に、
いくつもの壊れ方。

同じ写真を、CLEAN・単独のFAULT・CHAINで比較。
組み合わせによる違いを、撮影画面で確かめられます。

1.3.1開発版の撮影画面です。開発者が撮影した写真をエミュレーターのカメラ入力に使い、アプリで処理した結果を掲載しています。CHAINはLEVEL 100%に加え、ADVANCED MODEでBIT ERRORを強く設定しています。

TIME / INPUT / RECORDING

変わり続ける像を、
選んだ形式で残す。

設計について読む ↗

時間を操作する。

LIVEでは、変化の速さや大きさを調整できます。端末の動き、音量、カメラの撮影間隔、温度、処理負荷との連動も選べます。LIVEがOFFでも、各FAULTの基本的な揺らぎは続きます。

画面の一瞬を、保存する。

JPEGには、シャッターを押した時の表示画像を保存します。通常の動画も同じ処理を通した映像を記録します。保存解像度は、端末が対応するライブ映像の解像度によって変わります。

RAWでは、センサー側へ。

加工RAWで使えるのは、センサーからCFAまでの6種類のFAULTです。RAWはプレビューとは別に撮影するため、結果は画面と完全には一致しません。原本RAWとRAW動画のDNG連番は、FAULTをかけずに保存します。

FAULTは、カメラが捉えた信号をもとに故障を再現する処理です。被写体をAIで生成・補完することはありません。RGB画像でのCFA／DEMOSAICは色の復元過程を近似し、BLOCK／STREAMは復号後の画像上で崩れを再現します。

ON YOUR DEVICE

作品は、あなたの端末に。

画像処理と保存は、端末内で完結します。アプリの利用にアカウント登録は不要で、広告や利用状況の解析機能もありません。写真や動画を開発者へ自動送信することはありません。

位置情報の記録と音声の利用は、初期設定ではOFFです。必要なときだけ有効にできます。OSや写真アプリによるクラウド同期は、それぞれの設定に従います。
