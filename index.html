Android 12+ ／ 写真・動画 ／ 端末内で処理

ONE BROKEN SYSTEM

壊れ方に、個性を。
その瞬間に、偶然を。

壊れ方を決める「個体」、連続する「揺らぎ」、
一時的な「事故」。3つを分けて設計しています。

IDENTITY / 個体

壊れ方のくせが、残る。

故障が起きやすい位置や偏りを、カメラの個性として保ちます。SEEDを直接入力するか、RESEEDで別の個体へ。調整値と経路を保ち、適用するまで変更を試せます。

MOTION / 揺らぎ

同じ個体が、揺らぎ続ける。

読み出しのずれや露光のタイミングが、連続して変化します。FAULTごとの揺らぎが、同じ被写体に違う表情を生みます。

EVENT / 事故

一瞬の事故が、割り込む。

流れ続ける映像に、一時的な欠落や誤読が起こります。個体のくせや連続した揺らぎに、その時だけの崩れが加わります。

8 FAULT POINTS / MEDIA + DISPLAY

光が画像になる、
その途中へ。

FAULTは、信号が画像になる8つの段階に対応。
選んだ順番にかかわらず、この流れに沿って重なります。

  1. 01

    SENSOR

    撮像素子

    PIXEL DAMAGE

    暗い点、明るい点、縦に連なる画素の故障。

    EXPOSURE

    露光の欠落や、タイミングのずれによる帯。

  2. 02

    READOUT

    読み出し

    ROW ERROR

    読み出す行のずれや欠落、帯状の崩れ。

  3. 03

    DATA

    データ

    BIT ERROR

    画素データのビットが反転し、局所的に色や明るさが崩れる。

    ADDRESS ERROR

    読み取る位置のずれや領域の誤読。

  4. 04

    CFA / RECONSTRUCTION

    色の復元

    CFA ERROR

    色フィルター配列の対応がずれ、色の復元が崩れる。

    DEMOSAIC ERROR

    誤った周辺画素から色を補い、輪郭や細部が崩れる。

  5. 05

    COLOR

    色

    CHROMA ERROR

    明るさと色の成分を分け、色だけをずらす。

    COLOR MAP

    色の割り当てや繰り返しを変え、別のパレットへ。

  6. 06

    CODEC / STREAM

    圧縮・ストリーム

    BLOCK ERROR

    ブロックごとに階調が欠けたり、画像が崩れたりする。

    STREAM ERROR

    画像の一部が欠け、同じフレームの別の部分に置き換わる。

  7. 07

    MEDIA

    記録媒体

    VHS

    テープのにじみ、トラッキングの乱れ、欠落やノイズ。解像度低下は任意で選べます。

    DVD

    復号画像のブロック破損と欠落。DVD相当への解像度低下も選べます。

    DIGITAL THRU

    この段では画像を変えず、そのまま次へ通します。

    ANALOG THRU

    Composite／Component相当の解像度と、反射・同期ずれ・接触不良・干渉。

  8. 08

    DISPLAY

    表示

    CRT

    走査線や蛍光体の質感に、色ずれや同期の乱れを加えます。

    DIGITAL THRU

    アナログMEDIAの後では、ピクセル保持または線形補間で拡大します。

    NETWORK DISPLAY

    輻輳による画面停止、パケット領域の欠落、解像度低下。実際の通信は行いません。

    LED DISPLAY

    素子の粗さ、モジュール故障、走査帯を表現します。素子間の黒線は入れません。

CLEANはFAULTを適用しない状態です。LEVELを上げると、それぞれのFAULTに応じて故障の密度やずれ幅、事故の影響が変わります。ADVANCED MODEでは、内部の値を自動調整に任せるか、自分で固定するかを選べます。

実験機能を有効にすると、MOTION BLUR・THERMAL NOISE・SMEARも使えます。端末の状態に各FAULTが反応する強さも調整できます。実験機能とADVANCED MODEは、初期設定ではOFFです。

各FAULTの詳しい説明を読む ↗

ONE SCENE / THREE SIGNAL PATHS

ひとつの景色に、
いくつもの壊れ方。

同じ写真を、CLEAN・単独のFAULT・CHAINで比較。
組み合わせによる違いを、撮影画面で確かめられます。

作例は1.3.1開発版の撮影画面です。操作画面は現在の1.5.1と一部異なります。開発者が撮影した写真をエミュレーターのカメラ入力に使い、アプリで処理した結果を掲載しています。CHAINはLEVEL 100%に加え、ADVANCED MODEでBIT ERRORを強く設定しています。

TIME / INPUT / RECORDING

変わり続ける像を、
選んだ形式で残す。

1.5.1の操作ガイド ↗

時間を操作する。

LIVEで変化の速さや端末入力との連動を調整できます。実験機能TIME ECHOは、一つの確率操作で過去の映像を不規則に割り込ませます。FAULTは現在の状態で処理します。

TAPで、素材を流し込む。

実験機能をONにすると、写真・動画と並ぶTAPタブが現れます。選んだ素材をREADOUT後、DATA前へ入力。動画素材の再生・停止はプレビュー内、出力の録画は撮影ボタンで操作します。

RAWでは、センサー側へ。

加工RAWでは基本6種類のFAULTに加え、有効にした実験機能のブレ・熱雑音・スミアを使えます。RAWはプレビューとは別に撮影するため、結果は画面と完全には一致しません。原本RAWとRAW動画のDNG連番は、FAULTをかけずに保存します。

JPEGは処理済みの信号を保存し、ADVANCED ONでは表示フレームを確保します。MP4も同じ処理画像を記録します。FAULTはカメラまたは選択素材をもとに故障を表現する処理です。被写体をAIで生成・補完することはありません。RGB画像でのCFA／DEMOSAICは色の復元過程を近似し、BLOCK／STREAMは復号後の画像上で崩れを再現します。

ON YOUR DEVICE

作品は、あなたの端末に。

画像処理と保存は、端末内で完結します。アプリの利用にアカウント登録は不要で、広告や利用状況の解析機能もありません。写真や動画を開発者へ自動送信することはありません。

撮影画面を離れるか画面をロックすると録画を終了・保存し、プレビューと素材再生も停止します。戻っても録画は自動再開しません。位置情報の記録と音声は初期OFFです。OSや写真アプリによるクラウド同期は、それぞれの設定に従います。
