# Website assets

Updated 2026-09-09 for the 5igna1 closed-test recruitment page.

- `assets/icon.png`: existing 5igna1 logo from the main repository, Apache-2.0. See main `docs/audit/ASSETS.md`.
- `assets/01-camera.png`, `02-row.png`, `03-chain.png`: unedited 1080×1920 captures of the current 1.3.1 development UI, generated by existing `DeviceChecks` instrumentation (`action=screenshots`) on Android Emulator API 37. Camera source: `-camera-back imagefile:<source-still-life.jpg> -camera-front none`. CLEAN / ROW ERROR (LEVEL 98%) / ROW ERROR + CHROMA ERROR + VHS (LEVEL 95%). The capture-only instrumentation settings were temporarily increased for this page and restored afterward. Effects are processed by the actual app; no UI was composited and no effect was painted into the screenshots. The HTML scales images and clips the lower part of gallery previews; the hero shows a complete capture.
- Photograph fed to the camera: **Apples - Massachusetts.jpg**, by **Daderot**, original size 2240×2240. **CC0 1.0 Universal Public Domain Dedication**, verified in the file's Licensing section. Overhead still life of red/yellow apples in a metal bowl, no people or logos. Source: https://commons.wikimedia.org/wiki/File:Apples_-_Massachusetts.jpg . Original file: https://upload.wikimedia.org/wikipedia/commons/e/ea/Apples_-_Massachusetts.jpg . The camera crops/scales the source and the app applies its FAULT processing.
- The original camera source photo is retained in the local application verification folder; the public site contains the captured app UI only. The gallery caption links to the source and states that the image was supplied to an emulator, not photographed live on a physical phone.
- App interface: project Apache-2.0. Android system interface: Android Open Source Project, Apache-2.0. Photograph: CC0. See LICENSE and NOTICE.
- No generated artwork, external fonts, stock image services, analytics, cookies or JavaScript libraries are embedded. The recruitment button links to the owner's Google Form.

The initial version used the AOSP fake-camera house pattern. It has been replaced with the photograph above at the owner's request.
