# Website assets

Created 2026-09-09 for the Japanese 5igna1 landing page.

- `assets/icon.png`: existing 5igna1 logo from the main application repository, Apache-2.0. Original project artwork; see main's `docs/audit/ASSETS.md`.
- `assets/01-camera.png`, `02-row.png`, `03-chain.png`: unedited 1080×1920 screenshots of the 1.3.1 development build, generated by the existing `DeviceChecks` instrumentation (`action=screenshots`) on Android Emulator API 37, with `-camera-back emulated -camera-front none`. Japanese UI, CLEAN / ROW ERROR / ROW ERROR + CHROMA ERROR + VHS. No personal camera scene was used. The HTML scales the images and clips the lower part of gallery previews; the hero shows the complete capture.
- Screenshot inputs: the fake camera's generated house pattern from Android Open Source Project `device/generic/goldfish/camera/fake-pipeline2/Scene.cpp`, Copyright 2012 The Android Open Source Project, Apache-2.0. This is a test scene, not a real-world camera sample. App UI is the project's Apache-2.0 work.
- No new generated artwork, external fonts, stock photographs, analytics, cookies or JavaScript libraries are included.
