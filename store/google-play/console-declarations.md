# Play Console 申告下書き

5igna1 1.0.0の現在のコードを基にした下書きです。公開対象ビルドとConsoleの質問文を照合して提出してください。

| 項目 | 回答案 / 根拠 |
|---|---|
| 広告 | 含まない。広告SDKなし |
| アプリへのアクセス | すべての機能に制限なくアクセス可能。ログイン・招待・購読不要。カメラ等のOS権限を許可して使用 |
| データの収集 | 収集しない。アプリが端末外へデータを送信する実装・INTERNET権限・解析SDKなし |
| データの共有 | 共有しない。ユーザー操作による外部ビューアでの閲覧はあるが、自動の第三者送信なし。ユーザーが明示的に開始した転送に関するPlayの例外定義を確認 |
| アカウント作成 | なし。アカウント削除機能／URLは該当なし |
| カテゴリ案 | 写真 |
| ターゲットユーザー | 所有者が意図する対象年齢を選択。子供向けとする設計・素材は用意していない |
| レーティング | 写真／動画作成ツールとしてIARC質問票に回答。アプリ提供の暴力・性的表現・賭博・ユーザー間交流なし。最終レーティングはIARCが決定 |
| 課金・販売価格 | 課金機能なし。無料／有料の販売方針は所有者が決定 |
| 金融・健康・政府・ニュース | 該当する機能なし |

位置情報、カメラ画像、マイク音声は端末内で処理します。Playの「収集」は端末外への転送が基準なので、権限があることだけで収集ありと回答するものではありません。端末OSやユーザーが設定した写真バックアップ、問い合わせメールの取扱いはポリシーに記載しています。将来クラウド保存・解析・広告を追加したら、この回答は更新が必要です。

## 権限の用途

- CAMERA: ライブプレビュー、写真撮影、動画録画。
- RECORD_AUDIO: 音声ONの動画撮影時。音声OFFなら不要。
- ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION: 利用者がONにした撮影位置タグ。初期状態OFF、前面使用中のみ。
- バックグラウンド位置情報、全ファイルアクセス、写真ライブラリ全体の読取り権限は要求しません。自分で撮影したメディアをMediaStoreに保存します。

## 審査者向け操作メモ

起動後にカメラを許可 → エフェクトを選択 → 下部の丸い撮影ボタンで保存。動画は「動画」タブを選び撮影開始／停止。右上の歯車で形式・解像度・位置情報を変更。「＋ チェーン」で複数選択、「調整」でパラメータを変更。左上の5igna1または設定下部からプライバシーポリシーを開けます。メールへの送信は利用者自身がメールアプリで行います。
