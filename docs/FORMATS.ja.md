# 保存形式

撮影画面を離れるか画面をロックすると録画を終了・保存します。[録画と権限](RECORDING.ja.md)。

[English](FORMATS.md) · [ガイド](README.ja.md)

| 形式 | 記録する信号 |
|---|---|
| JPG | 処理済みカメラ画像とFAULT状態。ADVANCED ONでは表示済み画像を確保 |
| MP4 | 同じ状態進行で処理したカメラ画像の区間 |
| RAW（DNG） | 別露光RAWへ、固定した同じFAULT状態を適用 |
| RAW動画ZIP | 無加工・無音の時刻付きDNG連番 |

ADVANCED OFFでは処理済み出力1枚を再利用し、シャッター処理時に画像と状態を確保してから保存します。表示フレームと一致しない場合があります。ONでは表示済みテクスチャを同期的に確保し、3枚の履歴で後続フレームによる上書きを防ぎます。どちらもFAULTの全処理と確保後の画像・状態の不変性を維持します。解像度は対応するライブ出力から選びます。[端末推奨設定](PERFORMANCE.ja.md)はRAM・CPU数・対応出力を参考にし、手動サイズや最大も選べます。

JPEGはVHS／CRTを含む選択経路の出力です。JPEG圧縮や動画圧縮による画素差は生じます。動画の高fps時に画面の更新が間引かれても、記録と表示は同じ処理画像から作ります。

加工RAWはPIXEL DAMAGE〜CFA ERRORの6種類に対応します。RGBプレビューは近似であり、RAWは別露光・別表現です。RAWを唯一の真とは扱いません。後段のCOLOR／VHS／CRTなどはBayer DNGへ書き込みません。ファイル説明には、固定したFAULT状態とRAW自身の露光が異なることを記録します。

内部ではFAULT POINTまでの因果順prefixを記録tapとして扱えます。現在の画面で保存するのは選択したRGB経路の最終出力、または既存のRAW出力です。[RAW動画](RAW_VIDEO.ja.md)

新しい写真（JPG／DNG）と通常動画（MP4）は、共通のカメラアルバム **DCIM/5igna1** に保存します。既存ファイルは移動しません。実験的なRAW連番ZIPは **Download/5igna1** に保存します。

開発版には端末に合わせた推奨設定と、プレビュー負荷の自動調整があります。[発熱・負荷対策](PERFORMANCE.ja.md)。

## 解像度連動オーディオ（実験）

設定内の独立したスイッチで、初期値はOFFです。通常動画の音声ON時だけ、実際の出力画素数に応じてモノラルAACを変更します。QVGA以下は8 kHz／24 kbps、VGA以下は16 kHz／48 kbps、HD以下は32 kHz／64 kbps、フルHD以下は48 kHz／128 kbps、それ以上は48 kHz／192 kbpsを要求します。OFFなら従来の48 kHz／192 kbpsです。端末AACエンコーダーの対応範囲を確認し、実際の録音設定は端末側で調整される場合があります。マイクを自動でONにせず、LIVE感度と無音のRAW連番には影響しません。

実験的な端末連動がONなら、加工RAWでもブレ・熱雑音・スミアを追加できます。対応範囲と近似の制限は[実験機能](EXPERIMENTAL_SIGNALS.ja.md)を参照してください。
