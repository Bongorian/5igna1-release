# 保存形式

[English](FORMATS.md) · [ガイド](README.ja.md)

| 形式 | 記録する信号 |
|---|---|
| JPG | 画面が受け取った処理済みカメラ画像とそのFAULT状態 |
| MP4 | 同じ状態進行で処理したカメラ画像の区間 |
| RAW（DNG） | 別露光RAWへ、固定した同じFAULT状態を適用 |
| RAW動画ZIP | 無加工・無音の時刻付きDNG連番 |

JPEGはシャッター操作時に表示済みテクスチャを確保し、その後のカメラフレームによる上書きを防ぎます。3つの保持枠に表示済み・表示待ちの画像を残し、画面が追いつかない場合は表示更新を待ちます。後続の別露光を再加工しません。解像度は実際の対応ライブ出力で、初期設定はメモリとカメラの対応出力を参考にした約1〜2MPの推奨サイズです。手動ではGPUのテクスチャ上限内の最大サイズも選べます。大きい設定ではfpsが低下する場合があります。

JPEGはVHS／CRTを含む選択経路の出力です。JPEG圧縮や動画圧縮による画素差は生じます。動画の高fps時に画面の更新が間引かれても、記録と表示は同じ処理画像から作ります。

加工RAWはPIXEL DAMAGE〜CFA ERRORの6種類に対応します。RGBプレビューは近似であり、RAWは別露光・別表現です。RAWを唯一の真とは扱いません。後段のCOLOR／VHS／CRTなどはBayer DNGへ書き込みません。ファイル説明には、固定したFAULT状態とRAW自身の露光が異なることを記録します。

内部ではFAULT POINTまでの因果順prefixを記録tapとして扱えます。現在の画面で保存するのは選択したRGB経路の最終出力、または既存のRAW出力です。[RAW動画](RAW_VIDEO.ja.md)

新しい写真（JPG／DNG）と通常動画（MP4）は、共通のカメラアルバム **DCIM/5igna1** に保存します。既存ファイルは移動しません。実験的なRAW連番ZIPは **Download/5igna1** に保存します。

開発版には端末に合わせた推奨設定と、プレビュー負荷の自動調整があります。[発熱・負荷対策](PERFORMANCE.ja.md)。
