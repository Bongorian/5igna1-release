# GPU詳細調査とLIGHT MODE — 2026-09-10

[詳細・測定方法](GPU_DETAIL_LIGHT.md) · [測定値](gpu-detail-light-results.json) · [動作モード](../PERFORMANCE.ja.md)

1.6.0以降の未リリース開発です。`936903f`を基点とする`codex/gpu-detail-investigation`で実装・検証し、Pixel 9のDEV版へ導入しました。リリース版・公開サイトは変更していません。

## 実装した変更

- **独立したLIGHT MODEを追加、初期OFF。** LIGHTをONにするとADVANCED／EXPERTはOFFになり、どちらかをONにするとLIGHTを解除します。両方OFFだけではLIGHTにはなりません。切り替えは即時保存し、FAULTの値は維持します。
- **LIGHTの表示用加工を実表示サイズまで縮小。** カメラ入力・写真の保存解像度は維持し、JPEG撮影時に最新入力を保存解像度で一度処理します。プレビューの引き伸ばしではありません。細部は保存画像と異なる場合があり、撮影フレームも最後の表示とは限りません。RGB録画とNETWORKの保持画像は元の解像度を維持し、RAWは別露光のままです。TIME ECHOの既存の低解像度履歴入力も維持します。
- **LED単独の最終コピー省略を共通適用。** 所有する未公開の出力先へ直接描ける場合だけ省略します。入力と出力が同じ場合、所有が不明な場合、複数段の組み合わせは従来経路です。全モードに適用し、シェーダーの式・近傍サンプル数・処理順は変更していません。

LIGHTで小さなプレビューを使うJPEG撮影にはフル解像度描画が追加されます。シャッター遅延の分位値は未測定です。既存の更新頻度・温度の自動制御は有効なままで、LIGHT独自の低fps上限は追加していません。

## 実測

端末設定は入力・保存3072×4080、表示領域986×1309。縮小処理は985×1309となり、中間出力画素数が約90%減ります。合成RGBA入力と表示転送を含む最初の詳細測定では、通常13段が**40.94→7.55ms**、CFA全域が16.74→6.54ms、DEMOSAICが8.15→4.46msでした。再測定値もJSONに保持しています。

実装したLED単独経路を実カメラ入力・1080×1920で旧経路と比較すると、4ラウンドの中央値で**3.680→2.895ms、約21%短縮**。比較画像は全バイト一致です。先の2D測定の9〜15%とは条件が異なるため、端末一般の改善率にはしません。

## 採用しなかった変更

CFA／DEMOSAICの不要な近傍読み出し省略・位相計算の共通化は、最終の729比較で全バイト一致しました。ただし速度改善が安定せず、1080pの読み出し省略ではCFAが6.557→6.344msの一方、DEMOSAICは2.620→2.805ms、13段は8.653→8.641msでした。恒等変換の専用化も含め、試作はテスト側に残し、製品のシェーダーは変更していません。

画面への最終転送の一律省略も、13段では効果が安定せず、撮影・履歴・録画・サイズ変換の制約があるため採用していません。複数段のMEDIA／DISPLAY最終コピー省略も保留です。

## 検証

- F-Droid debugのJVMテスト42件、ビルド、lint、英日中の翻訳キー検査を通過。
- LIGHTの排他切り替え・保存・再読込、表示985×1309／JPEG保存3072×4080を実機確認。撮影前のフル解像度カメラ画像は独立した旧レンダラーと全バイト一致。
- 表示サイズ変更でも保存サイズは維持。MP4 1080×1920、DNG 4080×3072を保存でき、録画後に縮小プレビューへ戻ることを確認。
- LEDは実カメラ／2D入力、出力先の所有が既知／不明、複数段、個体・強度変更、入力と出力の共有を含む49比較と、実カメラの計測4ラウンドで一致。
- NETWORKのフルサイズ保持、ADVANCEDの表示履歴、既存`capture-contract`の表示フレーム・JPEG画素・固定メタデータ検証を通過。通常撮影も通過。通常撮影の初回テストはLIGHTを引き継いで既存のメタデータ判定に失敗したため、テスト条件でLIGHTを明示的にOFFにして再検証しました。
- LIGHT検証で作成した写真・動画は削除し、設定を復元。UIはローカル画像で確認し、カメラを含む画像はコミットしていません。

給電中・クロック固定なしのPixel 9での結果です。GPU完了待ちを含む処理時間で、電力・長時間の発熱・カメラから画面までの遅延ではありません。低性能端末や消費電力の削減は未確認です。
