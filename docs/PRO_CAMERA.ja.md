# PRO撮影と撮影画面のレビュー

[English](PRO_CAMERA.md) · [操作ガイド](USAGE.ja.md) · [保存形式](FORMATS.ja.md) · [時間モデル](TIME_MODEL.ja.md)

1.7.1以降の開発ブランチ `codex/pro-camera-workspace` に実装しています。実カメラの調整と撮影画面の再配置を含みます。アプリのリリースはまだ行っていません。

## モードの役割

| 選択 | 役割 | 操作場所 |
|---|---|---|
| 写真／動画／TAP | 撮影形式・入力素材を選ぶ | シャッター直上。TAPは実験機能ONの場合のみ |
| AUTO／PRO | 実カメラの自動制御・対応する調整操作 | 上部。TAPと外部撮影依頼では非表示 |
| 通常／LIGHT／ADVANCED／EXPERT | 処理負荷、FAULT編集、撮影方式の違い | 設定の「処理モード」。既存の併用条件を維持 |

PROを有効にしても、実験機能やFAULTの値は変わりません。PRO内でも露出・WB・フォーカスを自動で使えます。AUTOに戻すとカメラ標準の要求値と自動フォーカスへ戻ります。調整値はレンズごとに保持します。AE／WB固定は一時的な操作で、カメラ再構成、PRO終了、新しいセッションで解除します。

## 配置の棚卸し

| 領域 | 配置・動作 | 意図 |
|---|---|---|
| 上部バー | ライト、保存形式、解像度／fps、AUTO／PRO、設定 | 撮影条件をまとめ、FAULTから分離 |
| 状態行 | 撮影準備、エラー、録画時間 | 通常時は短い表示にし、診断情報の羅列を避ける |
| プレビュー | 画角を切らない表示、FAULT表示、下中央のレンズ選択 | 構図を優先し、レンズ操作は像の近くに置く |
| 上部の補助操作 | 上部の位置情報・音声操作。OFF時も表示 | 撮影に関係する状態を表示 |
| PRO操作帯 | 実測シャッター／ISO、対応する露出・WB・フォーカス・レンズ調整 | 像を見ながら実カメラを調整 |
| FAULTバー | 選択数／適用数、LEVEL、展開・収納、LIVE切り替えと設定 | 常にすべての調整を並べず、必要時に開く |
| 展開したFAULT | チェーン、追加・解除、ランダム・RESEED、LEVEL、LIVE状態と時間操作、任意のECHO | 創作側の操作を一か所へまとめる |
| 撮影モード | 全言語でPHOTO・VIDEO・TAP | シャッター直上で位置を固定 |
| 最下段 | 左に保存メディア、中央にシャッター、右に前面／背面切り替え | 入力素材やPROの状態にかかわらず撮影位置を固定 |

縦画面ではこの順で配置し、横に広い画面では右側に操作、残りをプレビューへ割り当てます。操作領域は必要に応じてスクロールしますが、撮影モードとシャッターはスクロールの外に残します。PROとFAULTの調整シートはプレビュー領域を確保して開きます。PROは閉じても変更を保持し、FAULTは適用／取り消しを維持します。操作ガイドは説明対象のFAULTを一時的に展開し、終了時に元へ戻します。

プレビューの横スワイプは写真／動画を切り替え、チェーンを維持します。タップはAFの再要求です。タップ座標を測光・AF領域へ指定する実装はまだなく、表示するフォーカス枠は中央です。手動フォーカスをタップで上書きしません。写真プレビューには写真用連続AF、動画には動画用連続AFを対応時に指定します。

## 対応機能と併用条件

選択したカメラの特性と書き込み可能な項目を読み取ります。共通の設定は論理カメラ要求に設定し、物理センサー向けの個別上書きキーがある項目はそれを使います。個別上書きがないことを、共通設定も非対応であると誤判定しないようにしました。調整範囲は選択したセンサーの特性を使います。非対応の操作は省き、要求した設定とカメラが返した実測値を分けて表示します。

| 操作 | 対応・制約 |
|---|---|
| 露出補正 | AEと補正の要求キー、AE ON、有効な刻み幅・範囲。自動露出時のみ |
| AE固定 | 固定機能とAE／固定の要求キーに対応。自動露出時のみ |
| シャッター・ISO | MANUAL_SENSOR、AE OFF、露光・感度・フレーム時間の要求キーと範囲に対応。両方を指定 |
| 写真のシャッター範囲 | センサーの露光範囲と最大フレーム時間の範囲内。長時間露光ではプレビュー更新とタイムアウトも調整 |
| 動画のシャッター範囲 | さらに選択fpsへ収まる時間に制限。写真用の希望値は消さない |
| 高速動画 | PRO要求を一時的に無効化して自動制御 |
| ホワイトバランス | 公開された自動・プリセットのみ。AWB固定は対応する自動モード時のみ |
| 手動フォーカス | MANUAL_SENSOR、AF OFF、焦点距離の要求キーと可動範囲に対応。距離表示は校正済みレンズのみ |
| 絞り | 複数の公開値と要求キーに対応し、手動露出の場合のみ |
| 光学ND | 複数の公開フィルター濃度と要求キーに対応 |
| 手ぶれ補正 | 対応時に標準／OFF／光学式。光学式を明示した場合、競合する書き込み可能な電子補正をOFFにする |
| ちらつき補正 | 対応する値を自動露出で使用。FAULT側の照明周波数とは別 |

すべてのメーカー固有制御を公開する実装ではありません。手動色温度・RGBゲイン・色変換行列、タップ測光領域、シーン／HDR拡張、ノイズ低減・輪郭処理は今回の操作対象に含めません。電子手ぶれ補正とデジタルズームも追加しません。光学焦点距離はレンズ選択側で、公開された値だけを使います。

基準：Android公式の[撮影要求](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest)、[カメラ特性](https://developer.android.com/reference/android/hardware/camera2/CameraCharacteristics)、[要求ビルダー](https://developer.android.com/reference/android/hardware/camera2/CaptureRequest.Builder)。

## 撮影・保存との関係

- 変更はレンズごとに保存し、カメラへ送ります。実測値の反映には遅れや丸めがあるため、撮影前に確認できます。
- JPEGは処理済みのカメラフレームを保存し、RAWは別の露光を行う既存方式です。FAULTの処理経路は維持します。
- FAULTのEXPOSUREは画像処理、HOLDはFAULTの時間操作です。実カメラのAE固定や手動シャッターの代わりにはなりません。
- TAPではPROを使いません。素材に含まれる露出・色処理を引き継ぎます。
- 外部アプリからの撮影依頼はカメラ標準の自動制御を使い、通常利用のPRO設定を保持します。
- 録画・写真処理中は変更とカメラ切り替えを制限します。音声付き録画中の確認振動抑制も維持します。
- 保存ファイルの「この設定を使う」はFAULT設定を再利用します。PROの実カメラ設定は復元対象ではありません。
- カメラがPROの繰り返し要求を拒否した場合は、AUTOへ戻したことを表示します。レンズの希望値は保持します。

## レビューと検証

AUTO／PRO、FAULT収納／展開、写真／動画、TAPのON／OFF、縦横の配置、異なる対応範囲のレンズへの切り替えをレビュー対象にしています。撮影操作の見つけやすさと、設定値・実測値の区別も確認してください。コンピュータユース禁止の指示を維持しており、実機画面の目視レビューは未実施です。

自動テストでは露光範囲と動画fps、AE／AWBの依存関係、非対応・高速動画、保存形式、シャッター操作の対数スケールを確認します。Activityを開かないCamera2テストでは、画面外のYUV出力で手動シャッター・ISO、WB、AUTOへの要求と実測値の復帰を確認します。撮影ファイルの作成や画面取得は行いません。検証したエミュレーター以外の機種での動作は、引き続き実機確認が必要です。

2026-09-12の検証：単体テスト75件、F-Droid debug lint、両配布版のdebugとテストAPKのビルド、616件の翻訳検査が成功しました。Android 35エミュレーターのCamera2で露出8,000,000 ns・ISO 200・晴天WB（5）の返却値とAUTO復元を確認しました。UIテストはコンパイルのみで実行しておらず、スクリーンショット・目視確認は行っていません。

USBレビュー対応：撮影ボタンは高さ48dp、コンパクトなラベル12sp、編集選択肢14sp、調整値18spを基準に、余白を4/8/12dpで統一しています。プレビュー下部には焦点距離ボタンを横並びにし、センサー寸法が得られる場合は35mm換算の概算値を表示します。詳細には実焦点距離を残しています。位置情報と音声はプレビュー外の上部に配置し、音声はPHOTO時から切り替え可能です。

2026-09-12 USB実機検証（25060RK16C）：physical:0:2とphysical:0:3の両方で、手動露出8,000,000 ns・ISO 200・晴天WB（5）の返却とAUTO復元が成功しました。Activityを開かず、保存を伴わないオフスクリーンYUVで確認しています。物理レンズの個別上書き項目だけを全対応項目と誤認していた問題を修正しました。
