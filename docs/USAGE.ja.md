# 操作ガイド

チュートリアル対応版を初めて起動すると、カメラ権限の確認より先に5ページの操作説明が表示されます。「次へ」「戻る」で移動し、「スキップ」で途中終了できます。最後まで進むか閉じると、次回から自動表示されません。設定 → 操作チュートリアルからいつでも見直せます。設定の未確定の変更は保持され、チュートリアルを閉じても適用・破棄されません。日本語・英語・簡体字中国語に対応し、通信なしで利用でき、画面の再生成でもページを保持します。既存ユーザーにも、この機能を含む版への更新後に一度表示されます。

[English](USAGE.md) · [ガイド一覧](README.ja.md)

写真／動画でモードを切り替え、中央ボタンまたは音量キーで撮影・録画します。プレビューをタップするとフォーカス、横スワイプで単体FAULTを選択します。RAWは1×で撮影します。

プレビューの下に選択中のチェーンが並びます。「＋」で追加し、効果をタップして調整します。すべて削除すると加工なしになります。プレビューをスワイプすると単一効果に切り替わります。LEVELは各効果の内部機構に対応し、効果ごとに少数の名前付き操作値を持ちます。

編集パネルはライブプレビューの下に専用の領域を確保します。「＋」から全13種類の2列の一覧を開き、効果を選ぶと、上部に処理順で並びます。選択済み効果をタップすると、その効果だけの操作値を調整できます。「✓」で保存、「×」・戻る・外側タップ・アプリ離脱でキャンセルします。撮影前に編集を適用するか取り消してください。

シャッフルアイコンは利用可能な効果を2〜5個選び、各操作値と全体LEVELも生成します。メイン画面では即座に適用、編集パネル内ではドラフトとして試せます。メイン画面のランダムボタンを長押しすると、操作値と経路を保って個体差を再生成します。リセットは調整中の効果の操作値を戻します。録画中はドラフト編集とランダムチェーン生成を開始できません。

LIVEは時間の進み方・速度と逆行・秒単位の周期や更新間隔・変化の形を設定します。一時停止はカメラを動かしたままFAULTの変化を止め、「故障を発生」はその場で一時的な故障を起こします。端末入力は任意で、コールド起動時のLIVEはOFFです。[LIVE設定](LIVE_FAULT.ja.md)。

上部の形式表示からJPG・RAW（動画ではMP4・RAW ZIP）を切り替えられます。RAWでもVHS / MEDIAとCRT / DISPLAYを一覧に表示し、現像後の画像が必要な効果には形式の切り替えボタンを表示します。形式を変えてもチェーンと操作値を保持し、RAWでは対応する効果だけを適用します。編集内で形式を変えてもドラフトを引き継ぎます。その後キャンセルすると効果の編集は破棄しますが、明示的に選んだ撮影形式は維持します。

歯車から言語・形式・解像度・画質・GPSを選べます。JPEGは表示したライブ信号を保存します。初期設定は端末に合わせた約1〜2MPの推奨サイズです。手動サイズや最大も選べます。RAWは別露光であり、RGBプレビューと同一ではありません。[形式](FORMATS.ja.md)。

通常動画はH.264/H.265、端末対応の解像度・fps、4段階の画質、任意の音声録音を使えます。高fpsでは画面の表示フレーム数が録画より少なくなることがありますが、同じ処理画像を参照します。バックグラウンド移行・ストレージ不足などで録画を停止します。長時間の連続記録は未検証です。[RAW動画](RAW_VIDEO.ja.md)は無加工・無音のDNG連番です。

保存先は写真が`DCIM/5igna1`、通常動画が`DCIM/5igna1`、RAW連番ZIPが`Download/5igna1`です。左下のサムネイルから写真・動画共通のプレビューを開けます。左右スワイプで撮影結果を切り替え、写真はピンチで拡大できます。動画は再生・一時停止・シークに対応します。下スワイプか×で撮影画面に戻り、↗で現在の項目を他のアプリで開きます。DNGは端末が提供するサムネイルでプレビューし、RAW ZIPは外部アプリで開きます。

GPSは初期OFFです。JPEGには表示信号のcamera timestampとFAULT状態をEXIFへ記録し、対応する取得結果があれば露光・ISOを付けます。RAWは自身の露光情報を保持します。[プライバシー](PRIVACY.ja.md)

設定で **ADVANCED MODE** をONにし、選択中のFAULTをタップで内部値を確認・固定できます。モードをOFFにしても固定値は保持されます。[全パラメータ](ADVANCED_MODE.ja.md)。

新しく撮るJPG・DNG・MP4はすべて **DCIM/5igna1** に保存します。既存ファイルは元の場所に残ります。実験的なRAW ZIP連番は **Download/5igna1** です。

開発版には端末に合わせた推奨設定と、プレビュー負荷の自動調整があります。[発熱・負荷対策](PERFORMANCE.ja.md)。

設定の「モード」にADVANCEDとEXPERTをまとめています。ADVANCEDは内部値の表示、EXPERTはアプリの更新頻度制限・冷却休止を外して速度を優先するモードです。[動作モード](PERFORMANCE.ja.md)。

上部には形式メニュー、ライト・GPSのアイコン、常時表示の動画音声アイコン、設定を配置しています。ライトとGPSは有効時にライム色になり、長押しで状態を確認できます。形式メニューはボタンの直下に開きます。撮影画面にロゴは置かず、アプリ情報は設定内にまとめています。FAULT STATEはプレビューを覆わず、時間と突発的な故障のメーターを表示します。0%でも固有の変化や固定加工は続く場合があります。

カメラ切断、またはプレビューが6秒間表示されない状態を検知すると、撮影中・冷却休止中を除き、前面動作中に最大3回再接続します。それでも復帰しない場合はプレビューをタップして再試行できます。録画は自動再開しません。保存プレビューから戻る際、保存先が変わっていなければ直近のサムネイルを保持します。
