# 操作ガイド

[ガイド一覧](README.ja.md) · [English](USAGE.md) · [最初の1枚](GETTING_STARTED.ja.md)

撮影から、効果の調整、保存した作品の閲覧までを説明します。

## 目的から操作を探す

| 画面 | 目的 | タップや変更の意味 |
|---|---|---|
| 撮影画面 | これから撮る写真・動画を決める | 映像のタップでAFを再要求。横スワイプでPHOTO／VIDEOを切り替える |
| FAULT・LIVEの編集プレビュー | 未確定の設定を映像で試す | ✓で確定、×・戻る・外側タップ・アプリ離脱で取り消す |
| 保存作品のビューア | 保存した作品と、その作品の設定を見る | 写真の拡大・作品の切り替え・動画の再生 |
| TAP | 写真・動画を素材として新たに加工する | 実験機能をONにして素材を選び、シャッターで新しく保存する |

撮影画面のタップは、タップした座標をAF領域に指定する機能ではありません。中央にフォーカス枠を表示して再要求し、PROの手動フォーカスは上書きしません。撮影画面のピンチによるデジタルズームはありません。

## 撮影画面の配置

上部にライト・位置情報・音声・形式・解像度・設定、その下に撮影準備の状態を表示します。写真と動画はシャッター上の**PHOTO／VIDEO**タブで選びます。左下は作品ビューア、中央はシャッター、右下は前面／背面カメラの切り替えです。同じ向きのレンズは映像内の焦点距離ボタンで選びます。端末が公開するレンズのみ選べ、RAW対応や解像度も選択したカメラに依存します。

**FAULT**バーの山形アイコンで操作を展開します。選択チェーン、＋、シャッフル、LEVELを使えます。LIVEがONなら一時停止・故障を発生・時間リセットも表示します。操作が見えないときはFAULTバーを展開してください。横画面は左が映像、右が操作部です。操作部の収納アイコンで折りたたんでもシャッターは残ります。

## FAULTを選び、編集プレビューで確かめる

1. ＋でチェーン編集を開き、一覧の行をタップして追加・解除します。すべて解除すると加工なしになります。
2. 行のスライダーアイコン、または撮影画面の選択済みチップで個別調整を開きます。上の映像には編集途中の状態が反映されます。
3. STREAM ERRORはデジタル／アナログFPV、MEDIAはVHS・DVD・Digital thru・Analog thru、DISPLAYはCRT・Digital thru・Network・LEDを選べます。モデルにより操作項目が変わります。
4. ✓で確定して撮影へ戻ります。×・戻るなどで閉じると編集前へ戻ります。撮影前に確定または取り消してください。

処理順は固定です。選択数と実際の適用数は、RAWやTAPなどの条件で異なる場合があります。無効な項目は理由とともに残します。**LEVELは全体の適用量**で、0%ならバイパスします。撮影画面のLEVEL変更は即時反映、編集内の変更は未確定です。編集内で明示的に保存形式を切り替えた場合、その形式選択は効果の取り消しでは戻りません。[効果とモデル](EFFECTS.ja.md)。

## 「ランダム」「RESEED」「リセット」を使い分ける

| 操作場所・操作 | 変わるもの | 確定のタイミング |
|---|---|---|
| 撮影画面のシャッフルをタップ | 使用可能な効果から通常2〜5個のチェーン、操作値、SEED、全体LEVEL | 即時。取り消し用の編集画面は開かない |
| 撮影画面のシャッフルを長押し | 現在有効な効果のうち、SEEDを使うものの模様・個体差 | 即時。チェーン、LEVEL、操作値を保持 |
| チェーン編集上部のシャッフル | 新しいランダムチェーンと値を試し表示 | ✓で採用、×で編集開始前へ戻る |
| 個別編集のSEED入力／RESEED | その効果の模様・個体差 | ✓で採用。操作値は保持 |
| 個別編集のリセット | その効果の操作値を既定値へ戻し、内部固定値を解除 | ✓で採用。構造的なSEEDは保持 |

**まず試してから選ぶなら、＋で編集を開いてからランダムを使います。** ランダムは一回ごとに設定を生成する操作で、時間に沿って変化させるLIVEとは別です。録画中はランダム生成・RESEED・チェーン編集を開始できません。対応効果が少ない場合は2個未満になることがあります。LEVELが0、効果がバイパス中、SEEDを使わないモデルなどではRESEEDしても見た目が変わらないことがあります。[SEEDと再現の範囲](SEEDS.ja.md)。

## LIVEを撮影画面で使う

1. FAULTを選び、LEVELを0より上にします。FAULTバーで**LIVE ON**にします。
2. バーを展開し、**一時停止**を押すと故障の状態を保持します。カメラ映像は動き続けます。**再開**で時間変化へ戻ります。
3. **故障を発生**で一時的な故障を加えます。効果の種類や操作値により見え方が違い、停止中に加えた状態は再開・リセットまで保持します。
4. **時間リセット**はFAULT時計を先頭に戻し、手動の発生を解除します。チェーンや操作値の初期化ではありません。
5. LIVE横の調整アイコンで、速度・変化の形・周期などを上の映像で試します。✓で確定、×で取り消します。

LIVE OFFは「加工なし」でも「すべて静止」でもありません。アナログFPVなど、固有の時間変化を持つ効果は動き続けます。加工全体を外すにはLEVELを0%にします。FAULT STATEのイベント%は一時的な事故の強さで、0%でも固定加工や固有の動きは残ります。

まず入力を追加せずに時間操作を試せます。端末の動き・音量などへの反応は任意です。LIVEと一時停止はコールド起動時にOFFへ戻り、その他の設定は保持します。通常動画の録画中も撮影画面の時間操作を使えますが、詳細編集は録画前に済ませます。[時間設定・入力・TIME ECHO](LIVE_FAULT.ja.md)。

## 保存形式・撮影・カメラ調整

上部の形式表示で、対応カメラではJPG／RAWを切り替えます。解像度は上部のサイズ表示、またはPHOTO／VIDEOタブの長押しで選びます。長押しでは撮影モード自体は変えません。中央シャッターまたは音量キーで写真撮影・録画開始・停止を行います。

動画は通常MP4です。設定でRAW動画の切り替えを有効にした場合だけMP4／RAW ZIPも選べます。RAW ZIPは無加工のDNG連番で常に無音です。RAW写真には対応するセンサー系効果のみ適用し、RGBプレビューは近似です。JPGは処理済み画像を保存し、ADVANCED ONでは表示フレームを保持します。[保存形式](FORMATS.ja.md)。

**設定 → モード → PRO撮影モード**をONにすると、対応する実カメラの露出・WB・フォーカスなどを調整できます。変更は即時保存です。FAULTを調整するADVANCEDとは役割が違います。[PRO撮影](PRO_CAMERA.ja.md)。

録画中にホーム・他アプリ・画面ロックへ移ると、録画を終了し、それまでの記録を保存します。戻っても録画は自動再開しません。動画モードは音声設定にかかわらず確認振動がOFFです。写真モードの確認振動は維持します。[録画と権限](RECORDING.ja.md)。

## 保存した作品のビューア

左下のサムネイルから開きます。未撮影でも開けます。

| 範囲 | 配置と操作 |
|---|---|
| ビューア全体 | 上部の×で閉じる。「写真を開く」で別の写真を選ぶ |
| 閲覧中の一覧 | ヘッダー直下の左右矢印と枚数。複数枚の場合のみ表示 |
| 表示中の作品 | 下部に日時・形式、SIGNAL、外部アプリで開く↗ |
| 表示中の動画 | 作品下部に再生／一時停止・時間・シーク |

写真はピンチで拡大し、拡大中はドラッグで移動、タップで拡大を解除します。拡大解除後は左右スワイプで作品移動、下スワイプで閉じます。動画の画面タップは再生／一時停止です。DNGは利用可能なサムネイルを使い、表示できないファイルは下部の↗から対応アプリで開きます。

JPG・DNG・MP4は`DCIM/5igna1`、RAW ZIPは`Download/5igna1`に保存します。[プライバシー](PRIVACY.ja.md)。

## 写真のやりとりで設定を受け渡す

1. ビューア上部の**写真を開く**で、受け取った写真を選びます。実験機能やTAPは不要です。
2. 写真下部の**SIGNAL**を開き、記録されたチェーンと操作値を確認します。開くだけでは撮影設定は変わりません。
3. **この写真の設定で撮る**を選ぶと適用し、撮影画面へ戻ります。自分の保存作品では**この設定を使う**から適用できます。

チェーン・LEVEL・操作値・SEED・詳細パラメータ、記録があれば実験機能のON/OFFを反映します。撮影形式・解像度・LIVE設定は維持します。元の写真は変更しません。設定情報が欠ける・未対応の場合は適用できず、見た目から推測して復元しません。

**元ファイルをやりとりしてください。** SNSや再保存でメタデータが消える場合があります。同じ設定でも、被写体・入力素材・LIVE時刻・端末入力まで復元できず、同じ画像になる保証はありません。1.7.0以降の保存MP4は録画開始時の設定を記録し、途中の変更履歴は含みません。

## 写真自体を加工するTAP

TAPでは、選んだ写真・動画を素材にして新しい作品を作れます。設定で実験機能をONにしてTAPを選び、Androidの選択画面で素材を開きます。READOUTの後、DATAの前から入るため、SENSOR・READOUTは通りません。シャッターでJPG／MP4を新しく保存し、原本は変更しません。

動画素材の再生／一時停止と出力録画は別々です。素材を停止したまま動くFAULTを録画することもできます。画面を離れると素材再生と録画の両方を停止します。[TAPと実験機能](EXPERIMENTAL_SIGNALS.ja.md)。

## 設定・更新・困ったとき

設定は変更時に保存され、閉じても取り消しません。PRO、ADVANCED、LIGHT、EXPERTは目的が異なります。まず推奨解像度で始めてください。[詳細調整](ADVANCED_MODE.ja.md) · [負荷と動作モード](PERFORMANCE.ja.md)。

不具合報告では**診断情報を確認**で版・端末・GPU・撮影モード・モデルなどを確認し、必要な場合だけ**診断情報をコピー**します。写真の設定メタデータとは独立し、作品への書き込みや自動送信・自動添付はありません。

Google Play版は設定のアプリ欄で更新を確認します。「確認中」「更新あり」「現在更新なし」「確認できない」を区別します。Playアカウントと配布対象に依存し、DEV版からリリース版の更新は確認できません。F-Droid／GitHub版にはこのサービスはありません。

**設定 → 操作チュートリアル**から12ステップのガイドを再表示できます。LEVELと形式のみ独立した練習操作があり、撮影設定や作品は変更しません。ガイド中はカメラを休止し、閉じると戻ります。日本語・英語・簡体字中国語に対応し、オフラインで使えます。

カメラが再接続できない場合は、案内に従い撮影プレビューをタップして再試行できます。録画は自動再開しません。[困ったとき](TROUBLESHOOTING.md)。
