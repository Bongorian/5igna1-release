# 使い方

## 撮影と切り替え

- 「写真」「動画」で撮影モードを切り替えます。中央ボタンまたは音量キーで撮影・録画開始／停止。
- 映像の左右スワイプで単体エフェクトを切り替え、映像をタップしてAF。
- 1×／2×のデジタルズーム、前後カメラ切り替え、対応カメラのライトを利用できます。RAWでは1×固定です。
- 「保存済み」で直近の画像・動画を外部ビューアへ渡します。DNGにはRAW対応の現像アプリが必要です。

撮影設定は右上の歯車アイコンから開きます。RAW非対応のカメラへ切り替えるとJPEGへ切り替わります。

設定の先頭にある「アプリの言語」で、端末の言語・日本語・English・简体中文を選び、適用します。初期設定は端末の言語です。未対応の言語では英語を表示します。エフェクト名など既存の英語表記は共通です。言語の変更後も撮影設定・エフェクト・LIVEの状態を引き継ぎます。

## エフェクトと調整

「CLEAN」で加工を解除します。単体ボタンやスワイプで選ぶと、それまでのチェーンは解除されます。

「＋ チェーン」で処理順に並ぶカードから複数選択できます。「調整」で選択中の各段を開き、強度・個別パラメータを変更します。OFFの段は「調整」を開くだけではONになりません。

全体と各段の強度は0〜100%。実際に使う段の強度は **全体強度 × 段の強度** です。OFFや強度0ではパラメータを動かしても加工されず、その理由を調整画面に表示します。

調整中は背景の映像へ試し表示します。

- **適用**：編集内容を確定・保存します。録画中なら、以後の録画映像にも反映します。
- **戻る／外側タップ／アプリを離れる**：編集を破棄して確定済みの状態へ戻します。
- 試し表示だけの設定を写真や録画へ混ぜません。調整画面を閉じてから写真を撮影してください。
- 各段の「標準に戻す」で調整値を初期化。「配置を変える」で対応するエフェクトの空間パターンを更新します。

「ランダム」の短押しで単体エフェクト、長押しでチェーンをランダムに変更します。チェーンは2〜4段です。各段のパラメータも変更し、全体強度は35〜85%の範囲で選びます。

調整値は次回も使えるよう記憶します。有効な段の選択とは別に管理しています。モードに非対応の段は選択から外れ、元のモードへ戻しても勝手に復活しません。RAW原本は設定を覚えたまま加工をバイパスします。

## 写真の保存形式

| 形式 | 処理 |
|---|---|
| 加工JPEG | 静止画出力をGPU加工し、品質85／95／100で保存 |
| RAW原本 | センサーデータを加工せずDNGで保存 |
| 加工RAW | センサー系8種をRAW16の画素データに適用し、DNGで保存 |

RAWプレビューは近似です。RAWの向き・Bayer配列・現像処理を含め、現像結果と完全には一致しません。写真は `Pictures/5igna1` に保存します。

## 動画と長時間録画

HEVC/H.265とAVC/H.264、対応する解像度・fps、4段階のビットレート設定を選べます。音声はON/OFF可能です。動画は `Movies/5igna1` に保存します。

アプリ独自の総録画時間制限はありません。約3.5GBごとに次のMP4へ分割し、空き容量が256MBを下回ると保存して終了します。画面消灯やアプリの背景移動でも録画を終了します。

録画中はアプリを前面に置いてください。長時間動作は電池・発熱・OSやカメラの中断にも依存し、数時間の連続録画は未検証です。

## 位置情報とメタデータ

GPS記録は初期状態OFFです。画面下部の「GPS」から「撮影位置をONにする」を押し、Androidの位置情報権限を許可します。「正確」と「おおよそ」のどちらでも撮影できます。画面では未許可・端末の位置情報OFF・測位中・取得済みを分けて表示します。権限が拒否されている場合はアプリの権限設定に進めます。測位結果の精度・経過時間を確認し、「現在地を再取得」で再試行できます。取得から2分以内の位置を写真と動画へ記録します。動画は録画開始時点の位置を使い、測位できない場合はGPSなしで保存します。

写真には日時・機種・露出・ISO・焦点距離などのメタデータと加工内容を記録します。アプリはネット通信、背景位置情報、既存メディア全体の読み取り権限を要求しません。

## LIVE FAULT

LIVE FAULTは起動時OFF。ONにすると、端末を動かさなくても各段のパラメータと強度を変化させます。設定で間隔・発生率・持続時間・変化量・なめらかさ、チェーン切替の許可を調整できます。変化の終了時とOFF時は手動設定へ戻ります。[詳細](LIVE_FAULT.ja.md)を参照してください。

## 撮影画面の操作

左下のサムネイルは最後に保存した写真・動画を開きます。動画には再生マーク、サムネイルを取得できないDNGにはRAW表示を付けます。右下のカメラアイコンで前後を切り替えます。LIVE FAULTはランダムの隣にあるON/OFFボタンで切り替え、右端のスライダーアイコンから自動変化の設定を開きます。


## RAW動画

撮影設定の「RAW動画 / DNG連番」をONにして動画モードへ切り替えます。対応するカメラだけで利用でき、解像度と目標fpsを選べます。原本・無音で保存し、エフェクトとLIVE FAULTは適用しません。出力はDownload / 5igna1のZIPです。展開してRAW対応ソフトでDNG連番を読み込んでください。詳しい制約と調査結果は[RAW動画](RAW_VIDEO.ja.md)を参照してください。
