# 操作ガイド

[English](USAGE.md) · [ガイド一覧](README.ja.md)

写真／動画でモードを切り替え、中央ボタンまたは音量キーで撮影・録画します。プレビューをタップするとフォーカス、横スワイプで単体FAULTを選択します。RAWは1×で撮影します。

CLEANはFAULTなし。単体選択で複数FAULTの経路を解除します。FAULT POINTSで複数を選ぶと、信号の因果順で適用します。LEVELは各故障機構へ個別に変換されます。調整項目の種類・数はFAULTごとに異なります。

調整中は背景にドラフトを表示します。「適用」で保存、戻る・外側タップ・アプリ離脱でキャンセルします。リセットは操作値のみ、RESEEDは選択した故障個体のみを変更します。Chainのランダム切替はありません。録画中はドラフト編集を開始できません。単体の選択など確定操作は後続の録画フレームに反映します。調整中に音量キーでJPEGを撮る場合も、そのとき表示している画像を保存します。

各FAULTは固有の時間変化を持ちます。LIVEは動き・音量・温度・カメラ時間・処理負荷を結合し、コールド起動時はOFFです。[LIVE設定](LIVE_FAULT.ja.md)。

歯車から言語・形式・解像度・画質・GPSを選べます。JPEGは表示したライブ信号を保存します。標準は2 MPまで、最大候補は8 MPまでの対応ライブ信号です。RAWは別露光であり、RGBプレビューと同一ではありません。[形式](FORMATS.ja.md)。

通常動画はH.264/H.265、端末対応の解像度・fps、4段階の画質、任意の音声録音を使えます。高fpsでは画面の表示フレーム数が録画より少なくなることがありますが、同じ処理画像を参照します。バックグラウンド移行・ストレージ不足などで録画を停止します。長時間の連続記録は未検証です。[RAW動画](RAW_VIDEO.ja.md)は無加工・無音のDNG連番です。

保存先は写真が`Pictures/5igna1`、通常動画が`Movies/5igna1`、RAW連番ZIPが`Download/5igna1`です。左下のサムネイルで直近の保存結果を開けます。

GPSは初期OFFです。JPEGには表示信号のcamera timestampとFAULT状態をEXIFへ記録し、対応する取得結果があれば露光・ISOを付けます。RAWは自身の露光情報を保持します。[プライバシー](PRIVACY.ja.md)
