# 検証範囲と制限

[ガイド](README.ja.md) · [English](VALIDATION.md) · [開発手順](DEVELOPMENT.ja.md)

1.7.4はlint、4構成それぞれ82件（合計328件）の単体テスト、FOSS依存関係検査、署名なしFOSSリリースビルド、両配布構成のデバッグビルドを通過しました。追加したJVMテストは、全モデルの有効な詳細項目と設定スナップショットの一致判定を検査します。公開パッケージでは既存の配布証明書・アプリID・版を検証します。

## 状態整合性の点検

- 詳細値は、対象段のマクロ・SEED・固定値・LEVEL・実験機能・カメラ接続世代が一致する場合だけ受け取ります。表示項目が評価結果に存在することも確認し、不足値をゼロで埋めません。
- STREAM／VHS／CRTのモデル選択時に画面を再構成します。固定モデルのスライダーもstreamKind／transportKindの両方で再構成するよう修正しました。Network displayの説明も古い設定・接続世代の値を受け取りません。
- カメラ接続・構成通知には世代判定、撮影結果には現在のセッション判定が既にあり、PRO画面はレンズ変更で閉じます。遅れて届く描画通知にもカメラ世代の判定を追加しました。
- RAW／写真／動画に応じた経路はスナップショット生成時に選別します。再接続は世代・設定の判定で保護します。これはソース点検であり、全センサー・形式の組み合わせを実機保証するものではありません。

元のADVANCED Analog FPVクラッシュは修正前1.7.3 DEVの実際の選択操作で再現しました。先行修正版はFPV GPU検査と3往復のモデル切り替えを通過しています。新しいeditor-transitionsはモデル選択・固定モデルスライダー、通常／ADVANCED、縦横、全グループ、古いSEED、適用／キャンセル、バックグラウンド復帰を検証します。接続した25060RK16Cで、固定モデルスライダーを含む80回の選択、全グループ、古いSEEDの除外、通常／ADVANCED、縦横、適用／キャンセル、バックグラウンド復帰を通過しました。

実機では背面広角・背面超広角・前面の3カメラを切り替え、撮影結果とJPEG焦点距離の一致、設定保持、デジタルクロップなし、物理センサーのDNG保存、MP4録画と録画中のレンズ変更防止を確認しました。最終1.7.4-debug／code 23を実機へインストール済みです。

Playで実際に更新がある状態の表示は対象アカウント・配布版が必要で、一連の動作は未検証です。アップロード、審査、テスター配信は[配布状況](LAUNCH_TASKS.md)で別々に管理します。

再確認は[UI検証](UI_REVIEW.ja.md)を参照してください。独立したRAW比較データとKotlin移行前の期待ハッシュはテストソースに保持しています。[測定データ](audit/README.ja.md)は当時の条件付きの記録であり、現在の性能を保証しません。

エミュレーターの結果は実機のRAW、音声品質、持続速度、発熱、電池消費を保証しません。広範な端末・数時間の録画・消費電力測定は未確認です。不具合報告には版、端末／OS、形式、解像度／fps、処理モード、再現手順を添えてください。
