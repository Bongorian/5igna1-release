# 検証範囲と制限

[ガイド](README.ja.md) · [English](VALIDATION.md) · [開発手順](DEVELOPMENT.ja.md)

1.7.3はlint、4構成それぞれ80件（合計320件）の単体テスト、FOSS依存関係検査、デバッグビルド、署名なしFOSSリリースビルドを通過しました。公開用パッケージでは既存の配布証明書・アプリID・バージョンも検証します。翻訳、依存関係一覧、リリース情報、リポジトリ、資料の検査も通過しました。

リリース準備前の実機DEV検証では、Analog FPVの無変化出力・決定的な再生・大きく滑らかに動く色ノイズ・局所的な干渉・6つの操作項目を確認しました。先行するUI修正ではPROの縦横画面と保存シグナルの動作を確認しています。USB再接続後、最終DEVビルドを25060RK16Cへインストールし、端末上で1.7.3-debug／versionCode 22を確認しました。

Playの実際の更新判定には、対象アカウントでPlayからインストールした公開版が必要です。ストア更新がある状態での一連の動作は未検証です。DEVにはパッケージの制約を表示します。更新SDKはPlay版だけに含み、アプリの権限は追加しません。

再確認は[UI検証](UI_REVIEW.ja.md)を参照してください。独立したRAW比較データとKotlin移行前の期待ハッシュはテストソースに保持しています。[測定データ](audit/README.ja.md)は当時の条件付きの記録であり、現在の性能を保証しません。

エミュレーターの結果は実機のRAW、音声品質、持続速度、発熱、電池消費を保証しません。広範な端末・数時間の録画・消費電力測定は未確認です。不具合報告には版、端末／OS、形式、解像度／fps、処理モード、再現手順を添えてください。
