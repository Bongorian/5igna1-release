# はじめての撮影

[English](GETTING_STARTED.md) · [ガイド](README.ja.md)

## 最初の1枚

1. カメラを許可し、**PHOTO**タブと上部の**JPG**を選びます。解像度は推奨から始め、位置情報や音声は必要な場合だけ有効にします。
2. **FAULT**バーを展開し、**＋**から**ROW ERROR**を選びます。スライダーアイコンで調整を開き、縦の線や動く被写体を見ながら「ずれ」「帯」「欠落」を試します。
3. 上の映像で確認し、**✓**で確定します。試す前へ戻すには**×**です。撮影画面のLEVELは全体の強さをすぐに変えます。
4. 中央シャッターまたは音量キーで撮ります。JPGは処理済み画像を保存します。RAWは別の露光を使い、表示と同一ではありません。
5. 左下のサムネイルで作品を開きます。写真はピンチで拡大し、タップで拡大解除。下スワイプか×で撮影へ戻ります。

## 次に試す操作

**組み合わせを試す：** ＋で編集を開き、その中のシャッフルを押します。新しいチェーンと値を映像で確認し、✓で採用、×で取り消します。撮影画面のシャッフルは即時に設定を作り直すため、取り消しながら試す場合は編集内を使います。撮影画面で長押しするとチェーンと操作値を保ち、SEEDだけを変えます。[ランダムとRESEED](SEEDS.ja.md)。

**時間を操作する：** LIVEをONにしてFAULTバーを展開し、一時停止／再開を試します。止まるのは故障の状態で、カメラ映像は動き続けます。隣の調整アイコンで速度や周期を試し、✓で確定します。端末入力は不要です。LIVE OFFでも固有に動く効果があります。[LIVEの使い方](LIVE_FAULT.ja.md)。

**写真から設定を受け取る：** ビューア上部の「写真を開く」で元の写真を選び、SIGNALを確認して「この写真の設定で撮る」を選びます。開くだけでは適用しません。写真そのものを加工素材にする場合は、別機能のTAPを使います。[作品の閲覧・設定の受け渡し・TAP](USAGE.ja.md)。

## 操作をもう一度確認する

**設定 → 操作チュートリアル**から12ステップのガイドを再表示できます。画面の役割と実際の操作位置を説明し、LEVELと形式には独立した練習操作があります。ガイド中はカメラを休止し、撮影設定や作品は変えません。次へ・戻るで読み進め、スキップでいつでも終了できます。

通常の設定画面は変更が即時保存され、×や戻るでは取り消しません。FAULT・LIVE編集の✓／×とは違います。PHOTO／VIDEOの長押しで解像度設定を直接開けます。
