# はじめての撮影

[English](GETTING_STARTED.md) · [ガイド](README.ja.md)

初回ガイドは8段階で実際の操作部をハイライトします。光る部分や練習ボタンをタップし、練習用LEVELを動かして試せます。練習では撮影設定を変えず、画像も保存しません。表示中はカメラ処理を停止します。**設定 → 操作チュートリアル**から再表示でき、選択済みの設定は保持されます。設定は選択時に保存され、×や戻るで閉じても保持されます。**推奨設定を使用**を選ぶとEXPERTもすぐOFFになり、自動負荷調整に戻ります。

カメラを許可し、写真モードの設定で「JPG」を選びます。まず標準ライブ解像度で始め、位置情報が不要ならGPSはOFFのままにします。

「＋」からROW ERRORを選び、チェーン内のROW ERRORをタップします。縦の線や動く被写体を探します。「ずれ」は横方向の読み出し、「帯」は構造、「欠落」は短い事故を変えます。背景で確認し、「✓」で確定、戻るでキャンセルします。

設定を変えずに眺めてください。同じ弱い行が動きます。気になった瞬間に中央シャッターまたは音量キーを押すと、処理済み画像をJPEGへ保存します。ADVANCED ONでは表示フレームを確保します。左下のサムネイルから開けます。保存先は`DCIM/5igna1`です。

「＋」でCHROMA ERRORやVHSを追加すると信号順に重なります。RAWでも全種類を表示し、これらの効果を使うときはJPEGへの切り替えを案内します。

シャッフルアイコンは2〜5個の効果と操作値を生成します。長押しすると経路と操作値を保ち、別の故障個体を作ります。LIVEは端末の動きなどを選択した系へ結合します。LIVEがOFFでも各FAULTは固有の時間変化を持ちます。[LIVE設定](LIVE_FAULT.ja.md)。

[保存形式](FORMATS.ja.md) · [表現の出発点](RECIPES.ja.md)

今のFAULTがどう変化するかはLIVEで設定します。周期・更新間隔は秒単位です。[時間変化の操作](LIVE_FAULT.ja.md)。内部値を直接固定するには、設定で [ADVANCED MODE](ADVANCED_MODE.ja.md) を一括ONにします。
