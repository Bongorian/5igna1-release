# はじめての撮影

[English](GETTING_STARTED.md) · [ガイド](README.ja.md)

カメラを許可し、写真モードの設定で「JPEG · 表示した信号」を選びます。まず標準ライブ解像度で始め、位置情報が不要ならGPSはOFFのままにします。

ROW ERRORを選び、縦の線や動く被写体を探します。LEVELを動かし、FAULTの調整を開きます。「ずれ」は横方向の読み出し、「帯」は構造、「欠落」は短い事故を変えます。背景で確認し、「適用」で確定、戻るでキャンセルします。

設定を変えずに眺めてください。同じ弱い行が動きます。気になった瞬間に中央シャッターまたは音量キーを押すと、その表示信号をJPEGへ保存します。左下のサムネイルから開けます。保存先は`Pictures/5igna1`です。

FAULT POINTSでCHROMA ERRORやVHSを追加すると信号順に重なります。単体を選ぶと複数FAULTの経路を解除し、CLEANでFAULTなしに戻ります。

RESEEDは経路と操作値を保ち、別の故障個体を作ります。LIVEは端末の動きなどを選択した系へ結合します。LIVEがOFFでも各FAULTは固有の時間変化を持ちます。[LIVE設定](LIVE_FAULT.ja.md)。
