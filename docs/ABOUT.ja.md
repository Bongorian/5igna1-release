# 一期一会のグリッチ

[English](ABOUT.md) · [5igna1](../README.ja.md)

センサーから読み出し、再構成、符号化、媒体、表示まで。画像になる経路には、ずれ・欠落・誤読が起こり得る地点があります。5igna1はそれを撮影の道具にします。

中心は「再現可能な性格 × 再現できない瞬間」です。同じ故障個体の位置やbiasを保ち、その内部の動きや一時事故を進めます。被写体、光、端末入力、シャッターのタイミングが、その状態に出会います。

乱数で作るのは個体差・drift・事故であり、被写体の内容ではありません。画像は実カメラから始まり、欠落を黒・noise・取得済みサンプルで表現します。RAWも経路上の表現の一つです。

内部には因果的な整合性を持たせつつ、完全な工学シミュレーションより、表現と撮影体験を優先します。VHS／CRTの装置特性と内部故障も分けて扱います。

JPEGは処理済みカメラ信号を撮り（ADVANCED ONでは表示フレームを確保）、、通常動画は同じ系の状態進行を区間として記録します。RAWは異なる表現・露光で、RGB画面とは同一ではありません。[FAULT](EFFECTS.ja.md) · [記録形式](FORMATS.ja.md)
