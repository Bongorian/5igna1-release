# SEEDとRESEED

> 開発版の時間規則・モデル別の有効項目・SEEDは[時間モデル2](TIME_MODEL.ja.md)に従います。公開版の挙動はそのリリースタグの資料を参照してください。

[ガイド](README.ja.md) · [English](SEEDS.md)

**SEED**はFAULTの模様・個体差を決める値です。通常／ADVANCEDのどちらの編集画面でも、数値を押して符号付き64ビット整数を入力できます。**RESEED**は新しい値を生成します。表示はその場で更新され、適用で保存、戻る／×で取消になります。−9223372036854775808〜9223372036854775807の範囲外は、下書きを変えずに拒否します。

| 操作 | 変わるもの | 保持するもの |
|---|---|---|
| SEED入力／個別RESEED | 選択中の構造的な個体値 | 経路、LEVEL、調整値、内部の固定値、固定EVENT SEED |
| メインのシャッフルを長押し | 現在有効でSEEDを使うFAULTの個体値 | RAW／TAP／実験機能で無効な段と各調整値 |
| シャッフルを押す | ランダムな経路、調整値、個体値 | 選ばれなかった段の保存値 |
| 選択FAULTのリセット | 調整値を既定値に戻し、固定値とEVENT SEEDを解除 | 構造的なSEED |

録画中は再生成できません。COLOR MAP、MOTION BLUR、SMEAR、Digital thruは構造的なSEEDを使用しないため、再生成操作を表示しません。LEVELが0、一時事故が発生していない、下流の値が固定されている、といった場合もSEED変更が見た目に出ないことがあります。

**EVENT SEED**は、事故を生成するFAULTのADVANCED画面で事故系列を個別に決めます。AUTOでは構造的なSEEDと固定の定数から導出します。固定EVENT SEEDは構造的なSEEDを変更しても保持され、AUTOで構造的なSEEDからの導出へ戻ります。内部カタログの縮約された描画値 `identitySeed`／`eventSeed` とは別です。

内部の固定値は生成値より優先されます。RESEEDで意図した固定値を消さないため、新しい個体値に追従させたい項目はFIXからAUTOに戻してください。再生成はFAULT時計のリセットや素材の再生操作ではありません。

同じSEED・設定なら空間的な模様を再現できます。事故のタイミングには同じAUTO／固定EVENT SEED・FAULT時間・入力・調整値も必要です。LIVE BURSTは経路の順序と各ステージのSEEDに従います。画像全体には同じ素材サンプルも必要で、動いている実カメラの場面をSEEDだけで再現することはできません。TIME ECHOの発生タイミングは別の乱数モデルです。
