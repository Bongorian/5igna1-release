# LIVE FAULT

起動時はOFF。ONにするとアプリ内部の乱数と時間で、各段の強度・パラメータと全体強度を変化させます。端末を動かす必要はなく、センサーやマイクの追加取得も行いません。外部プレビューから戻るとON/OFFを維持して再開します。

- 間隔：0.5〜10秒ごとに変化の発生を判定。
- 発生率：判定ごとの確率。0%では発生せず、100%では毎回発生。
- 持続時間：0.15〜5秒。次の変化が発生した場合は新しい目標値で再開。
- 変化量：手動値からランダムな目標値への変化幅。0%では手動値を維持。
- なめらかさ：変化の入りと戻りの時間。0%は瞬時に切替。
- チェーン切替：初期OFF。許可すると変化中に対応エフェクトを指定範囲の段数で選択。OFFでは手動で選んだ段を維持。

ランダムチェーンの段数は1〜16段の最小・最大で指定します（初期2〜4）。実際の候補数を上限とし、維持する表示段が設定上限より多い場合は表示段の数を優先します。すべての端末で選択できますが、多段ではGPU負荷が上がりフレームレートが下がります。

SENSOR FAILは、元の手動チェーンに含まれるときだけランダム候補になります。「元の表示段を維持」は初期ONで、元のVHS / TERMINALをチェーン内に残し、別の表示段は追加しません。OFFでは表示段も再抽選されます（同じ段が再び選ばれることもあります）。維持するのは段の選択で、パラメータの自動変化は続きます。

撮影画面の「LIVE」行に実際の処理チェーン・段数・全体強度を表示し、該当するエフェクトボタンを点灯します。行をタップするとチェーン全体を確認できます。手動設定の強度スライダーは基準値を保持します。

変化が終わると手動設定に戻ります。LIVE FAULTをOFFにしても同様です。自動変化は手動の選択・パラメータを書き換えません。CLEAN・RAW原本・RAW動画は加工しません。加工RAWでは対応段だけを適用するため、切替後の段数は少なくなる場合があります。

プレビューと動画は同じフレームの値を共有し、写真は撮影時の値を固定して保存します。各パラメータと強度は0〜1の範囲です。設定値は保存しますが、起動時のON/OFFは保存しません。
