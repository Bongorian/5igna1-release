# LIVE FAULT

[English](LIVE_FAULT.md) · [FAULT](EFFECTS.ja.md) · [ADVANCED MODE](ADVANCED_MODE.ja.md)

LIVEは「今この瞬間にFAULTが時間に沿って変化すること」を表します。時間の進み方、変化の形、任意の端末入力を設定します。LIVEがOFFでもFAULT固有の変化は進み、ONにすると指定した時間操作と変化量を適用します。コールド起動時はLIVE・一時停止ともOFFで、それ以外の設定を保存します。

LIVE横の調整ボタンで開きます。カメラ映像を上に残し、下のパネルで調整します。変更は独立した下書きでプレビューし、適用すると設定と時間状態を引き継ぎます。閉じると破棄します。設定は録画前に行い、撮影画面の時間操作は通常録画中も使えます。

| 項目 | 役割 |
|---|---|
| 時間の進み方 | 連続・ループ・往復・一定間隔で更新 |
| 変化速度・逆行 | −4倍〜＋4倍。負数で逆行し、0倍で時計を止める |
| 変化の形 | 固有の変化・周期的な増減・蓄積と解消・断続的な発生・チェーン内の推移 |
| 変化・反復の周期 | 1周期の秒数（0.25〜32秒）。ループや往復の時間範囲にも使う |
| 更新間隔 | 一定間隔で更新する時計の秒数（0.015625〜2秒） |
| 変化量 | 変化の谷でどこまで強さを減らすか |
| 発生が続く割合・発生確率 | 断続的な発生の継続割合と、周期ごとの発生確率 |

周期と間隔は秒で指定します。以前のBPM・拍数の設定は、同じ長さの秒数へ引き継ぎます。速度はFAULTの時間に作用するため、周期はその時間軸上の長さです。カメラや動画の時刻は順方向に進み、過去のカメラ映像を再生する機能ではありません。端末入力が変わればループの結果も変わります。

**一時停止／再開・故障を発生・時間リセット**を等幅・等間隔に配置しています。一時停止はカメラを動かしたまま、FAULTと評価済みの入力寄与を保持します。「故障を発生」は今この時点で一時的な故障を起こし、停止中に発生させると再開・リセットまで保持します。「時間リセット」は時計を0へ戻して手動の発生を解除します。選択したチェーンは保持します。LEVELが0なら全FAULTをバイパスし、ADVANCEDの固定値は有効なFAULTで優先します。

## 端末入力の棚卸し

| 設定 | 計測元 | 実際の接続先 |
|---|---|---|
| 動き・回転 | 利用可能な加速度・ジャイロ | 行の読み出しずれ、VHSのトラッキング、CRTの同期ずれ |
| 音量 | 任意のマイク入力、または録音中のレコーダー | テープの時間軸の揺れ、トラッキング波 |
| 露光・読み出しタイミング | カメラのメタデータと配送間隔 | 露光の位相・積分、読み出しと事故の圧力 |
| 温度 | バッテリー温度とAndroidの温度状態 | 輝点の明るさ、センサーノイズ |
| 処理負荷 | このアプリのCPU時間と経過時間 | データ・ストリームの事故の発生率と影響 |
| 感度 | 動き・音・配送間隔・CPUの結合ゲイン | 温度には固有の対応付けを使う |
| 照明の電源周波数 | 50／60 Hz | 対応メタデータが得られる場合の露光位相・積分 |

取得できない入力の値を作りません。展開した欄に利用状況と計測値を表示します。温度・CPUは代理指標で、壊れたセンサーや通信路を直接測っているわけではありません。音を有効にして適用したときに必要なマイク権限を確認し、拒否された場合も他の入力は使えます。録音中は既存レコーダーの振幅を使い、別マイクを開きません。カメラがバックグラウンドへ移ると入力を解放します。

プレビューと通常動画は各カメラ時刻の同じ処理画像を使います。JPGは表示した画像を保持して保存し、RAWは別露光に対応するセンサー系FAULTを適用します。RAW動画のZIPは引き続き無加工です。[保存形式](FORMATS.ja.md)。
