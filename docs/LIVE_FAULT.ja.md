# LIVE FAULT

[English](LIVE_FAULT.md) · [FAULT](EFFECTS.ja.md)

各FAULTは、LIVEがOFFでも固有の時間変化を持ちます。弱い行は動き、テープでは一時的なdropoutが起こりますが、個体差は保持されます。LIVEは端末状態をその系へ結合する機能です。

| 入力 | 結合先 |
|---|---|
| 動き・回転 | 読み出しのずれ、tracking、CRTの同期 |
| 露光・skew・カメラの時間情報 | 露光位相・積分、読み出しの不安定さ |
| 温度状態 | 輝点の活動量、センサーノイズ |
| CPU・カメラの処理圧力 | data／stream事故の確率・影響 |
| 音量 | テープの時間軸の動き |

LIVE横の設定から入力・感度・照明の50/60 Hzを選べます。コールド起動時はOFFです。音量入力は任意でマイク権限が必要です。拒否しても他の入力は使えます。音声録画中は録画側の音量を参照し、別のマイクを開きません。バックグラウンドでは取得を停止します。

選択した経路と手動設定を維持します。固定個体・遅いdrift・突発事故には別の乱数領域を使います。通常のChainランダム切替と、汎用的な全パラメータ補間はありません。RESEEDは同じ設定で別の故障個体を作ります。

通常の表示・動画は同じカメラフレームと状態から作る処理画像を参照し、JPEGはシャッター時の表示画像を固定して保存します。RAWは別表現・別露光です。[記録形式](FORMATS.ja.md)
