# 表現のレシピ

ここにあるのは出発点です。同じ設定でも光や被写体で印象は変わります。プレビューを見ながら、一つずつ強さを探ってください。

[ガイド一覧](README.ja.md) · [全エフェクトの仕様](EFFECTS.ja.md)

## 輪郭を横へほどく

**ROW SHIFT → CHROMA** / 加工JPEG・通常動画

「＋ チェーン」で2つを選びます。ROW SHIFTで行のずれを作り、CHROMAで色の境界をずらします。最初はCHROMAを弱くし、形が読める程度にROW SHIFTを調整すると、それぞれの働きを見分けられます。

縦の線や建物の輪郭など、ずれが見える被写体で試してみてください。RAWで試す場合はROW SHIFTだけが対応します。

## 古い映像の層を重ねる

**LINE LOSS → VHS** / 加工JPEG・通常動画

LINE LOSSで行を抜いたり繰り返したりしてから、VHSでトラッキングの乱れとノイズを重ねます。LINE LOSSの帯を大きくしすぎると被写体が隠れるので、少しずつ変えます。

動画ではLIVE FAULTをONにし、まず「チェーン切替」をOFFにすると、選んだ2段を保ったまま変化を探せます。手動の状態に戻すときはLIVE FAULTをOFFにします。

## データの崩れを現像する

**DATA SHIFT → CFA OFFSET** / 加工RAW対応カメラ

設定から「加工RAW」を選び、2つの効果をチェーンにします。DATA SHIFTはデータの並びをずらし、CFA OFFSETは色配列の位相を入れ替えます。まず各段を弱くして一枚保存し、DNGを現像アプリで開いて結果を確認します。

加工RAWのプレビューは近似です。プレビューだけで結果を決めず、DNGを現像しながら調整してください。比較用の原本が欲しい場合は、保存形式を「RAW原本」にして別に撮影します。原本と加工版を同時保存する機能ではありません。

## 思いがけない組み合わせを探す

「ランダム」を長押しすると2〜4段のチェーンになります。気になる組み合わせが出たら、各段の「調整」を開いて一つずつ弱め、何が像を変えているのか探します。

名前付きプリセットの保存機能は現在ありません。再現したい設定はチェーンと調整値をメモしてください。アプリは各段の調整値を記憶しますが、モードを変えると非対応の段が選択から外れます。

## 効果が見えないとき

全体強度と段の強度の両方を確認します。実際の強さは **全体強度 × 段の強度** です。段がOFF、強度が0、またはCLEAN・RAW原本を選んでいると加工されません。[困ったとき](TROUBLESHOOTING.md)
